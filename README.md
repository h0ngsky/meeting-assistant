# 会议助手

钉钉风格的会议室预约与日程管理 Web 应用。

## 功能

- **登录注册**：支持管理员（admin）与普通成员两种角色
- **会议室预约**：5 间会议室（201-205），按容量限制参会人数
- **会议邀请**：邀请在册成员参会，自动检测日程冲突
- **成员日程**：查看任意成员的会议安排
- **午休禁约**：12:30-14:00 普通成员不可预约（管理员除外）

## 会议室

| 编号 | 最大容量 |
|------|----------|
| 201  | 6 人     |
| 202  | 8 人     |
| 203  | 10 人    |
| 204  | 12 人    |
| 205  | 12 人    |

## 快速开始

```bash
cd meeting-assistant
npm install
npm start
```

浏览器访问 http://localhost:3001

**默认管理员账号**：`admin` / `admin123`

普通成员可通过注册页面自行注册。

## 技术栈

- 后端：Node.js + Express + JWT 认证
- 前端：原生 HTML/CSS/JS
- 存储：JSON 文件（`data/` 目录）
