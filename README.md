# 会议助手

一个开源的会议室管理预约助手，帮助团队高效预约会议室、协调日程、避免冲突。

## 功能

- **账号体系**：管理员与普通成员分权，支持注册登录
- **会议室预约**：按日查看空闲时段，拖拽选择时长，一键发起会议
- **冲突检测**：自动校验会议室占用、成员日程冲突与容量上限
- **日程协同**：个人日程日/月视图，可查看成员占用情况
- **规则管控**：支持午休禁约等预约规则（管理员可例外）
- **多端适配**：桌面与手机均可使用，移动端支持触控预约

## 快速开始

```bash
cd meeting-assistant
npm install
npm start
```

浏览器访问 http://localhost:3001

**默认管理员账号**：`admin` / `admin123`

普通成员可通过注册页面自行注册。

## 技术栈

- 后端：Node.js + Express + JWT 认证
- 前端：原生 HTML/CSS/JS
- 存储：本地 JSON；生产环境可接入 Redis
